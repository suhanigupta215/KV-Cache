## Focused structural comparison for counsel

The candidate combination in the frozen disclosure is **source-video metadata → pixel-to-token/page reconciliation → temporal state → generation-tagged tier descriptor → reserve/prepare/commit/ready K/V mapping → same-protocol semantic correction**. The sources above variously cover codec guidance, K/V paging, decoder memory allocation, tier compression, and selective refresh. This preliminary review has **not established** that the full combination is absent from any single source or non-obvious when combined. Counsel should create a limitation-by-limitation matrix against actual independent claims, full paper methods, and unpublished/earlier-priority family records.

Search strings for the professional continuation: `motion vector transformer KV cache page table`, `codec metadata descriptor memory controller attention`, `video decoder semantic cache correction generation`, `asynchronous decoder KV allocation fence`, `visual token page residency motion residual`, plus CPC/IPC searches and backward/forward citations from the identified patent families. Search India, PCT, US, EP, CN and non-patent literature; record query, database, date, result set, and excluded references.

The frozen document lists arXiv:2604.06036 as CodecSight; the [current arXiv page](https://arxiv.org/abs/2604.06036) confirms that title and records version history. Some search indexes still surface an older/alternate title (“CoStream”); counsel should cite the exact version reviewed. The [current CoPE-VideoLM page](https://arxiv.org/abs/2602.13191) also uses a longer title than the frozen reference list. These bibliographic differences are not substantive novelty findings.
